# پرامپت طراحی و توسعه — دایان (Dayan)

تو طراح/توسعه‌دهنده محصول «دایان» هستی؛ دستیار دانشجویی PWA.

## محدودیت سخت
- فقط **دو پنل**: فرانت دانشجو (`:3000`) و پنل ادمین (`:3001`). پنل سومی وجود ندارد.
- فرانت: **Next.js**. بک‌اند: **FastAPI (Python)**.
- دیتابیس اصلی: **PostgreSQL**. لاگ و حافظه مکالمه: **MongoDB**.
- هیچ دادهٔ نمونه در UI ننویس. صفحه اصلی اسکلت خالی است تا ادمین پر کند. «فرم کارآموزی» فقط مثال محصول است، نه متن ثابت.
- همه خطاها، اعتبارسنجی‌ها و پاسخ API **فارسی** با شکل `{ "error_code": "...", "message": "..." }`.
- محصول باید برای تست نفوذ آماده باشد (rate limit، RBAC جدا، IDOR چک، آپلود با magic bytes، CORS محدود، JWT کوتاه + refresh، audit log).

## ظاهر — Liquid Glass
- فونت Vazirmatn، RTL، دارک/لایت.
- شیشه: `backdrop-filter: blur(26–30px) saturate(180%)`، هایلایت بالای کارت، شعاع ۲۴–۳۲px، رنگ ته‌مایه فیروزه‌ای/تیل (نه قرمز).
- **داک پایین** مثل داک مک: شناور وسط پایین، شیشه‌ای، حباب فعال با spring به آیتم انتخاب‌شده morph می‌شود.
- **حباب ایجنت**: گرد، شیشه‌ای، روی همه صفحات. کاربر می‌کشد؛ صفحه ذهنی دو نیمه است. اگر مرکز حباب در نیمه چپ باشد با فنر به لبه چپ می‌چسبد، اگر راست باشد به راست. موقعیت در localStorage می‌ماند. با کلیک، پنجره چت از **همان لبه** باز می‌شود.
- ایجنت صفحه فعلی را می‌داند (`current_page` + snippet صفحه). سنجاق فایل: عکس (jpg/png/webp/heic)، PDF، Word و مشابه برای تحلیل کارنامه.

## صفحه اصلی دانشجو (همه از ادمین)
هدر+لوگو قابل آپلود، اسلایدر بنر متحرک (اخبار دانشگاه + گروه کاربر)، دسترسی سریع، تقویم آموزشی، اطلاع‌رسانی قابل‌مرتب‌سازی، بخشنامه گروهی، فرم‌ها (ایجنت هم می‌تواند بدهد)، اساتید+امتیاز گروهی، بلوک تلگرام، نظرات تاییدشده. `target_groups` خالی = همه.

## ثبت‌نام / ورود
دانشجو: نام، نام خانوادگی، یوزرنیم، کد دانشجویی، رمز+تکرار، انتخاب گروه از لیست ادمین.
ورود: یوزرنیم یا کد دانشجویی + رمز.
ادمین: ثبت‌نام با شماره پرسنلی (اولین setup)، بعد لاگین با پرسنلی؛ دسترسی کامل جدا از کاربر.

## بعد از ورود
ایجنت با تاریخچه Mongo + context + Temporal برای کارهای چندمرحله‌ای.
اطلاع‌رسانی گروهی + PWA push (اجازه اعلان).
تیکت زنده WebSocket با ادمین: آنلاین بودن، درحال‌نوشتن دوطرفه، ارسال سند، بستن و ذخیره تاریخچه. چند تیکت همزمان با badge خوانده‌نشده در ادمین.

## پنل ادمین کنترل می‌کند
لوگو/برند، بنرها، دسترسی سریع، تقویم، اطلاعیه، بخشنامه، فرم، اساتید، تلگرام، نظرات، داک پایین، گروه‌ها، متن لاگین، قوانین ایجنت، ادمین‌های جدید، تیکت زنده، لاگ.

## مقیاس ~1M
FastAPI async چند اینستنس، Redis برای rate limit و Pub/Sub سوکت، Postgres با pool، Qdrant سرور نه فایل محلی، ISR/SSR صفحه اصلی، CDN برای فایل.
